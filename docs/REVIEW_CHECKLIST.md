# たばコン レビュー検査リスト

## A. 固定契約

- [ ] ゲーム名は「たばコン」
- [ ] game_slugは`tabakon`
- [ ] 公開URLを変更していない
- [ ] 🚬30個、20個成功、制限時間60秒
- [ ] スコア式、色別点数、指定結果コメントを変更していない
- [ ] 全10ステージ共通の`best` / `desc`ランキング
- [ ] `submit_score` / `get_best_score_ranking`を使用
- [ ] Publishable keyは`apikey`だけに使い、管理用キーを含まない

## B. 画面・入力・タイマー回帰

- [ ] 表示Canvas論理座標は320×480、内部世界は320×960
- [ ] 48×144グリッドと左端24pxスクロールバーを維持
- [ ] スクロール後も`screenToWorld()`で削る位置がずれない
- [ ] カメラ操作開始後に盤面へ入っても砂を削らない
- [ ] 砂削り開始後に左バーへ入ってもカメラへ切り替わらない
- [ ] READY中に時間と物理が進まない
- [ ] PLAYING開始時に60秒付近から始まる
- [ ] 処理落ち・バックグラウンド移動で残り時間が伸びない
- [ ] 20個到達時点で残り時間と結果が固定される
- [ ] 成功演出中に追加到達、喪失、物理、砂削りが進まない
- [ ] 成功フラッシュ後にRESULTへ1回だけ進む

## C. P0-B精密掘削・静的契約

- [ ] `CARVE_RADIUS = 11`
- [ ] `CARVE_STEP = 5`
- [ ] `CARVE_SETTLE_PADDING = 10`
- [ ] 通常入力に`carveEllipse(x, y, 20, 20)`が残っていない
- [ ] スワイプ補間に旧9px間隔が残っていない
- [ ] `beginCarveStroke()`で指押下時のストロークを開始する
- [ ] `recordCarvePoint()`は半径11pxで砂セルを削除する
- [ ] 実際に砂を削れた場合だけ`lastSuccessfulCarveAt`を更新する
- [ ] 実際に削れた地点の近くで休止中🚬を起こす
- [ ] `carveLine()`は前回点から今回点まで5px以下で補間する
- [ ] 同じ補間点を先頭で重複処理しない
- [ ] `finishCarveStroke()`で砂崩れを1回だけ起動する
- [ ] `settleSandBounds()`はストロークの変更範囲だけを対象にする
- [ ] `touchend` / `touchcancel` / `mouseup` / `mouseleave`でストロークを確定する
- [ ] PLAYINGから別状態へ移る際に未確定ストロークを処理する
- [ ] ストローク状態が`resetGame()`で前回プレイから残らない
- [ ] 固定壁は削れない
- [ ] 視覚フィードバックを補間点ごとに無制限生成しない

## D. P0-B精密掘削・実機合格

### D-1. タップ

- [ ] 1回の短いタップで直径40px規模の大穴が開かない
- [ ] 同じ地点で旧半径20pxより明確に狭く削れる
- [ ] 半径11pxでも砂を削ったことが目視できる
- [ ] 小さすぎて何度タップしても道が作れない状態ではない

### D-2. ゆっくりしたスワイプ

- [ ] ゆっくりなぞると幅がほぼ一定の連続した道になる
- [ ] 指の軌跡から大きく左右へはみ出して削れない
- [ ] 細い壁を残す、左右へ分岐させる操作ができる
- [ ] 同じ場所を往復しても不自然に広がり続けない

### D-3. 高速スワイプ

- [ ] 速くなぞっても5px補間により大きな未削除の隙間が出ない
- [ ] 高速入力で砂崩れを補間点数分連続実行しない
- [ ] 指離し時に長時間画面が固まらない
- [ ] 長い縦ストロークでもiPhone SE相当で操作不能にならない

### D-4. ストローク終了

- [ ] 指を離すまで変更範囲が正しく保持される
- [ ] 指離し時に変更範囲へ砂崩れが1回だけ適用される
- [ ] `touchcancel`でも砂崩れと入力状態が残らない
- [ ] タイムアウトまたはRESULT遷移中に指が残っていてもストローク状態が残らない
- [ ] 次プレイ開始時に前回の削除範囲が処理されない

### D-5. 推奨端末

- [ ] iPhone SE相当の小画面
- [ ] iPhone 11 Pro
- [ ] iPhone 17 Pro
- [ ] iPad Pro 2018

実機で半径11pxが狭すぎる場合は12px、まだ広い場合は10pxを比較する。実機結果なしに値を変更しない。

## E. 固定間隔物理

- [ ] `PHYSICS_DT`は`1 / 120`
- [ ] 1表示フレームの物理更新上限は6回
- [ ] 蓄積時間上限は`PHYSICS_DT * 6`
- [ ] requestAnimationFrameの表示周期と物理周期を分離している
- [ ] 成功演出中、RESULT、READYで物理蓄積値を進めない
- [ ] 復帰直後に大量の物理更新を一度に実行しない
- [ ] 30fps、60fps、120Hz相当で同一固定ステップ数なら大きく結果が変わらない

- [ ] 地形への法線速度36px/秒未満では反発係数が0

- [ ] 全接触セルの法線を食い込み量で重み付けして合成する
- [ ] 接地法線を連続フレームで平滑化する
- [ ] 平面判定は`abs(normalX) <= 0.12 && normalY < -0.95`
- [ ] 平面上で横速度12px/秒以下なら0へ吸着する
- [ ] 平面上でゴール方向への人工ナッジを加えない
- [ ] 平面接地が0.18秒以上安定してから休止判定へ入る
- [ ] 速度4px/秒未満が0.35秒続くと休止する
- [ ] 重なり量だけで休止中の🚬を起こさない

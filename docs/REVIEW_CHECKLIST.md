# たばコン レビュー検査リスト

## A. 現在の公開前確認

### 1. 固定契約

- [ ] ゲーム名は「たばコン」
- [ ] game_slugは`tabakon`
- [ ] 公開URLを変更していない
- [ ] 🚬30個、20個成功、60秒
- [ ] スコア式、色別点数、指定結果コメントを変更していない
- [ ] 全10ステージ共通の`best` / `desc`ランキング
- [ ] `submit_score` / `get_best_score_ranking`を使用
- [ ] Publishable keyは`apikey`だけに使い、管理用キーを含まない

### 2. 画面・入力・タイマー

- [ ] 表示Canvas論理座標は320×480、内部世界は320×960
- [ ] 48×144グリッドと左端24pxスクロールバーを維持
- [ ] スクロール後も`screenToWorld()`で削る位置がずれない
- [ ] READY中に時間と物理が進まない
- [ ] PLAYING開始時に60秒付近から始まる
- [ ] 処理落ち・バックグラウンド移動で残り時間が伸びない
- [ ] 20個到達時点で残り時間と結果が固定される
- [ ] 成功演出中に追加到達、喪失、物理、砂削りが進まない
- [ ] 成功フラッシュが描画されてからRESULTへ1回だけ進む

### 3. PR3固定間隔物理

- [ ] `PHYSICS_DT`は`1 / 120`
- [ ] 1表示フレームの物理更新上限は6回
- [ ] 蓄積時間上限は`PHYSICS_DT * 6`
- [ ] requestAnimationFrameの表示周期と物理周期を分離している
- [ ] 成功演出中、RESULT、READYで物理蓄積値を進めない
- [ ] 復帰直後に大量の物理更新を一度に実行しない
- [ ] 30fps、60fps、120Hz相当で同一固定ステップ数なら大きく結果が変わらない

### 4. 半径と初期配置

- [ ] `BALL_RADIUS = 8`
- [ ] `BALL_DRAW_RADIUS = 9`
- [ ] `BALL_SHADOW_RADIUS = 10`
- [ ] 個体の物理半径は`BALL_RADIUS`を使う
- [ ] 地形、仕掛け、トラップ、ゴール、🚬同士の判定で物理半径を使う
- [ ] 本体の見た目と判定の差は1px以内
- [ ] 初期配置の横・縦間隔は17px以上
- [ ] 30個が初期状態で重ならない
- [ ] 初期位置が外壁、固定壁、危険ゾーン、仕掛け内部にない

### 5. 地形衝突と高速移動

- [ ] 円と地形セルの最近接点で食い込みを解消する
- [ ] 1固定更新の移動距離に応じて最大4分割する
- [ ] 速度上限は900px/秒
- [ ] 高速落下で薄い固定壁を明らかにすり抜けない
- [ ] 左右・上の世界外へ出た場合に位置を戻す
- [ ] 地形角で1秒以上細かく震え続けない

### 6. 🚬同士の衝突

- [ ] active同士だけを判定する
- [ ] 全30個で最大435組を扱える
- [ ] 固定更新ごとに2回衝突を解決する
- [ ] 重なりを質量の逆数比で分離する
- [ ] 接近中だけ速度反発を入れる
- [ ] 接線方向に弱い摩擦がある
- [ ] 同一座標でもランダム震えを使わず固定方向で分離する
- [ ] normal 1.00 / red 1.25 / blue 0.80 / black 1.10の質量を使用する
- [ ] 30個が大きく重なったままにならない

### 7. 休止と復帰

- [ ] 接地・仕掛け非接触・3px/秒未満が0.6秒続くと休止する
- [ ] 休止中は速度を0にする
- [ ] 近くの砂を削ると復帰する
- [ ] 他の🚬から十分な食い込み/衝撃を受けると復帰する
- [ ] バー、ゲート、ローター接触で復帰する
- [ ] 支持地形がなくなると復帰する
- [ ] 休止中もゴール、危険、最下部、終了判定から除外しない

### 8. バー・ゲート・ローター

- [ ] バーの最初の強い上面接触だけ反発する
- [ ] 低速でバー上に接触した時は小刻みに跳ね続けない
- [ ] バー速度の一部が横速度へ伝わる
- [ ] バー端から自然に落下できる
- [ ] ローターの力は接触位置・速度・方向に依存する
- [ ] ローターの同一接触で毎固定更新ごとに力を足さない
- [ ] ローター接触待ち時間は約50ms

### 9. 終了・ランキング回帰

- [ ] `delivered + activeCount < NEED`で確定失敗する
- [ ] 一時停止2秒だけで誤終了しない
- [ ] 動きも砂削りも8秒ない時だけstalled終了する
- [ ] activeが0、全activeがゴール下で待たされない
- [ ] 結果は`resultFinalized`で1回だけ確定
- [ ] 1プレイにつき自動送信試行は1回
- [ ] 前回通信が次の結果画面を書き換えない
- [ ] 送信失敗時もランキング取得を試す
- [ ] 結果シェア文末尾に公開URLがある

### 10. 性能・検証

- [ ] JavaScript構文チェック成功
- [ ] HTMLにscriptが1つ存在し抽出できる
- [ ] ステージ検査警告が0
- [ ] 初期30個の中心距離が16px未満にならない
- [ ] 30個同時物理で処理が停止しない
- [ ] iPhone SE相当で30fpsを下回り続けない
- [ ] iPhone 11 Pro、iPhone 17 Pro、iPad Pro 2018で重大表示崩れがない
- [ ] 実機未確認項目を確認済みと記載していない

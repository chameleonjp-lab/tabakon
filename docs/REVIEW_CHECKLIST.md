# たばコン レビュー検査リスト

## A. 固定契約

- [ ] ゲーム名は「たばコン」
- [ ] game_slugは`tabakon`
- [ ] 公開URLを変更していない
- [ ] 🚬30個、20個成功、制限時間60秒
- [ ] スコア式、色別点数、指定結果コメントを変更していない
- [ ] 全10ステージ共通の`best` / `desc`ランキング
- [ ] `submit_score` / `get_best_score_ranking`を使用
- [ ] Publishable keyは`apikey`だけに使い、管理用キーを含まない

## B. 画面・入力・タイマー回帰

- [ ] 表示Canvas論理座標は320×480、内部世界は320×960
- [ ] 48×144グリッドと左端24pxスクロールバーを維持
- [ ] スクロール後も`screenToWorld()`で削る位置がずれない
- [ ] READY中に時間と物理が進まない
- [ ] PLAYING開始時に60秒付近から始まる
- [ ] 処理落ち・バックグラウンド移動で残り時間が伸びない
- [ ] 20個到達時点で残り時間と結果が固定される
- [ ] 成功演出中に追加到達、喪失、物理、砂削りが進まない
- [ ] 成功フラッシュ後にRESULTへ1回だけ進む

## C. 固定間隔物理

- [ ] `PHYSICS_DT`は`1 / 120`
- [ ] 1表示フレームの物理更新上限は6回
- [ ] 蓄積時間上限は`PHYSICS_DT * 6`
- [ ] requestAnimationFrameの表示周期と物理周期を分離している
- [ ] 成功演出中、RESULT、READYで物理蓄積値を進めない
- [ ] 復帰直後に大量の物理更新を一度に実行しない
- [ ] 30fps、60fps、120Hz相当で同一固定ステップ数なら大きく結果が変わらない

## D. 半径と初期配置

- [ ] `BALL_RADIUS = 8`
- [ ] `BALL_DRAW_RADIUS = 9`
- [ ] `BALL_SHADOW_RADIUS = 10`
- [ ] 個体の物理半径は`BALL_RADIUS`を使う
- [ ] 地形、仕掛け、トラップ、ゴール、🚬同士の判定で物理半径を使う
- [ ] 本体の見た目と判定の差は1px以内
- [ ] 初期配置の横・縦間隔は17px以上
- [ ] 30個が初期状態で重ならない

## E. 平面振動P0検査

この章は実機で全項目を満たすまでPR #24をReady化・マージしない。

### E-1. 低速反発

- [ ] 地形への法線速度36px/秒未満では反発係数が0
- [ ] 🚬同士の相対接近速度18px/秒未満では反発係数が0
- [ ] 重力で毎固定更新に生じる微小な接地速度が跳ね返らない
- [ ] 低速接地時に上下へ1px以上往復し続けない

### E-2. 接触法線

- [ ] 単一の最深セルだけではなく全接触セルの法線を合成する
- [ ] 食い込み量を法線の重みとして使う
- [ ] 接地法線を連続フレームで平滑化する
- [ ] 平面セルの境界上でも法線が左右へ交互に切り替わらない
- [ ] 地形角で法線が切り替わる場合も位置が往復し続けない

### E-3. 静止摩擦と斜面

- [ ] 平面判定は`abs(normalX) <= 0.12 && normalY < -0.95`
- [ ] 平面上で横速度12px/秒以下なら0へ吸着する
- [ ] 平面上でゴール方向への人工ナッジを加えない
- [ ] 斜面加速は接触法線へ投影した重力だけを使う
- [ ] 水平面に置いた1個が5秒以内に完全停止する
- [ ] 水平面上の中心位置変化が停止後1px未満

### E-4. 休止と復帰

- [ ] 平面接地が0.18秒以上安定してから休止判定へ入る
- [ ] 速度4px/秒未満が0.35秒続くと休止する
- [ ] 休止中は速度を0にする
- [ ] 両方休止中で重なり0.5px以下なら位置補正を行わない
- [ ] 重なり量だけで休止中の🚬を起こさない
- [ ] 相対速度8px/秒以上または衝撃量12以上で衝突復帰する
- [ ] 近くの砂削り、仕掛け接触、支持消失では復帰する
- [ ] 30個の山の下層が上層の微小補正だけで起き続けない

### E-5. 実機合格

- [ ] iPhone実機で平面上の目視可能な振動が1秒以上続かない
- [ ] 同じ平面へ3個並べても互いに震え続けない
- [ ] 10個を積み重ねても下層が連続して起きない
- [ ] 30個同時でも処理停止・NaN・画面外暴走がない
- [ ] バー上、地形角、ゴール前でも永久振動しない

## F. 高速移動・🚬同士の衝突

- [ ] 1固定更新の移動距離に応じて最大4分割する
- [ ] 速度上限は900px/秒
- [ ] 高速落下で薄い固定壁を明らかにすり抜けない
- [ ] active同士だけを判定する
- [ ] 全30個で最大435組を扱える
- [ ] 固定更新ごとに2回衝突を解決する
- [ ] 重なりを質量の逆数比で分離する
- [ ] 接線方向に弱い摩擦がある
- [ ] 同一座標でもランダム震えを使わず固定方向で分離する
- [ ] normal 1.00 / red 1.25 / blue 0.80 / black 1.10の質量を使用する

## G. バー・ゲート・ローター

- [ ] バーの最初の強い上面接触だけ反発する
- [ ] 低速でバー上に接触した時は小刻みに跳ね続けない
- [ ] バー速度の一部が横速度へ伝わる
- [ ] バー端から自然に落下できる
- [ ] ローターの力は接触位置・速度・方向に依存する
- [ ] ローターの同一接触で毎固定更新ごとに力を足さない
- [ ] ローター接触待ち時間は約50ms

## H. 終了・ランキング回帰

- [ ] `delivered + activeCount < NEED`で確定失敗する
- [ ] 一時停止2秒だけで誤終了しない

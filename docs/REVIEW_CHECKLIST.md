# たばコン レビュー検査リスト

## A. 現在の公開前確認

### 仕様・文書

- [ ] ゲーム名が「たばコン」。
- [ ] game_slug が `tabakon`。
- [ ] 公開URLが `https://chameleonjp.codeberg.page/tabakon/`。
- [ ] 🚬を🦊へ届ける内容。
- [ ] 30個中20個で成功し、20個到達後に終了する説明になっている。
- [ ] 制限時間が60秒。
- [ ] 10ステージは現在 `makeStage(name, shortName, variant)` による共通生成型であると説明されている。
- [ ] 現在のステージ選択はランダムで、同じステージが連続する可能性があると説明されている。

### スマホ表示・座標

- [ ] 表示Canvasは320×480相当のままで、ページ全体を960px表示にしていない。
- [ ] 内部ゲーム世界は320×960。
- [ ] 砂グリッドは48×144。
- [ ] 左端24pxの縦スクロールバーで上端から下端まで `cameraY` を動かせる。
- [ ] `screenToWorld()` により、スクロール後も削る位置が世界座標上でずれない。
- [ ] `setupCanvasResolution()` と `devicePixelRatio` によりCanvas内部解像度が調整される。
- [ ] ゲーム内の論理座標は320×480として扱われる。

### 画面状態・操作

- [ ] `HOME`, `RULE`, `READY`, `PLAYING`, `RESULT`, `ERROR` がある。
- [ ] READYで3、2、1のカウントが出る。
- [ ] READY中に時間が減らない。
- [ ] PLAYINGへ入った直後に60秒付近から始まる。
- [ ] PLAYING中だけ砂削り、物理、当たり判定、タイマーが進む。
- [ ] 処理落ちしても残り時間が伸びない。
- [ ] バックグラウンド復帰後に正しい残り時間になる。
- [ ] 左バー領域では砂が削れない。
- [ ] 砂削り中にカメラが勝手に動かない。
- [ ] リタイア前に確認ダイアログが表示される。
- [ ] リタイアすると5000点を引く。
- [ ] 結果画面の「もう一度」はHOMEへ戻らず、同じ名前でREADYから再開する。

### 砂・物理

- [ ] 砂は48×144グリッドで管理される。
- [ ] 砂削り後、削った周辺だけ `settleSandAround()` で局所崩落する。
- [ ] 砂を毎フレーム世界全体で動かしていない。
- [ ] 🚬に重力、横方向の減速、砂・壁・仕掛けとの当たり判定がある。
- [ ] 接地時の小さい上下速度が止まりやすい。
- [ ] 斜面方向への加速がある。
- [ ] 転がり速度に応じた表示回転がある。
- [ ] 着地時の軽い潰れ表現がある。
- [ ] ローターの接触位置と回転速度に応じた力がある。
- [ ] 最下部に落ちた🚬は失った扱いで消える。
- [ ] 停止時間を計測している。

### 終了条件

- [ ] 20個到達で短い成功演出後に結果へ進む。
- [ ] 20個到達時点でスコアが固定される。
- [ ] 成功演出中に21個目以降が加算されない。
- [ ] 60秒経過で結果へ進む。
- [ ] activeな🚬が0なら結果へ進む。
- [ ] `delivered + activeCount < NEED` で即失敗する。
- [ ] 全active🚬がゴールより下なら結果へ進む。
- [ ] 一時停止2秒だけで誤終了しない。
- [ ] 進展なし終了は成功した砂削りで延期される。
- [ ] 結果は1回だけ確定する。
- [ ] RESULT後に `stopLoop()` でゲームループが停止する。

### ランキング送信

- [ ] 終了時に自動で1回だけ送信。
- [ ] 1プレイ1送信。
- [ ] `submit_score` RPCで送信し、`/rest/v1/game_scores` へ直接insertしていない。
- [ ] `get_best_score_ranking` RPCで取得している。
- [ ] game_slug は `tabakon`。
- [ ] スコア順は `desc`、ランキング型は `best`。
- [ ] ステージ別ランキングではなく共通ランキング。
- [ ] Publishable keyのみ。
- [ ] Publishable keyをAuthorizationへ入れていない。
- [ ] 通信制限時間は8秒。
- [ ] 前回通信が次の結果画面を書き換えない。
- [ ] 送信失敗でもランキング取得を試す。
- [ ] 通信失敗でも結果画面が壊れない。

### シェア・デバッグ

- [ ] ホームシェア文の末尾に公開URL。
- [ ] 結果シェア文の末尾に公開URL。
- [ ] 成功、失敗、リタイアで文面が分かれる。
- [ ] Web Share APIまたはクリップボードコピーを使う。
- [ ] 現在は通常公開時にも `window.tabakonDebug` が作られる。

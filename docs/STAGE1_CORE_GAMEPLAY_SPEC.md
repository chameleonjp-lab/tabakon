# ステージ1 コアゲーム性再設計仕様

## 1. 目的

「中央を縦に掘るだけで20個以上届く」状態を禁止し、縦長世界を使った複数回の判断を成立させる。

ステージ1は、3室から最低2室を選び、中段で左へ寄せ、下層で右へ戻して右端の狐へ届けるS字ルートとする。

## 2. 固定契約

- 30個中20個で成功
- 制限時間60秒
- 320×480表示 / 320×960世界
- 地形グリッド48×144
- 掘削半径11px、補間5px、砂崩れ1回/ストローク
- スコア式、色別点数、指定結果コメント、Supabase RPC、共通ランキングを変更しない

## 3. 上層：3つの独立室

30個を10個ずつ、固定壁で分離した3室へ配置する。

| 室 | 内容 | 役割 |
| --- | --- | --- |
| 左室 | 白10個 | 安全・低得点 |
| 中央室 | 赤5個＋青5個 | 速攻・ゲート判断 |
| 右室 | 黒4個＋赤4個＋青2個 | 高得点・高危険 |

1室だけでは最大10個なので成功できない。最低2室を開放する。

## 4. 第1障壁：室ごとの出口

- 障壁行: y=34〜35
- 左室出口: x=6〜10
- 中央室出口: x=25〜29
- 右室出口: x=38〜42

出口直上の砂を削り、どの室を開けるかを選ぶ。

## 5. 第2障壁：左へ寄せる

- 障壁行: y=66〜67
- 開口: x=6〜13
- それ以外: 固定壁

中央と右の真下も固定壁で塞ぐ。上層から真下へ掘っただけでは通過できず、全て左側の開口へ誘導する必要がある。

盤面ラベル:

```text
← まず左へ
```

## 6. 第3障壁：右へ戻す

- 障壁行: y=102〜103
- 開口: x=34〜41
- それ以外: 固定壁

第2障壁の左開口を通った🚬を、下層で右へ戻す。左を真下へ掘り続けても第3障壁で止まる。

盤面ラベル:

```text
右の狐へ →
```

## 7. ゴール

- goal.x: 176
- goal.w: 116
- 中心X: 234
- 右端側に配置

狐絵文字は回収枠中央へ描画し、見た目と判定位置を一致させる。

## 8. 必須プレイ手順

1. 上層で最低2室を選ぶ
2. 第1障壁の砂栓を開ける
3. 中段で左開口へ誘導する
4. 画面を下へ移動する
5. 下層で右開口へ誘導する
6. 右端の狐へ届ける

最低でも「室選択」「左誘導」「右誘導」の3段階判断を発生させる。

## 9. ルート特性

### 左室

- 白10個
- 危険が少ない
- 得点効率は低い

### 中央室

- 赤5個・青5個
- ゲートのタイミングを使う
- 中得点・短時間候補

### 右室

- 黒4個・赤4個・青2個
- 危険帯とローターを使う
- 高得点だが事故率が高い

## 10. 主な戦略

- 左＋中央: 初心者向け、安全寄り
- 左＋右: 時間を使う高得点候補
- 中央＋右: 最短・最高得点候補だが危険
- 3室すべて: 操作量が増えるが失敗分を補える

## 11. レビュー用固定選択

`?stage=1`を付けた場合だけステージ1を固定選択できる。通常URLでは10種類からランダム選択する。

## 12. 自動検査

- typePlanが30件
- 左室が白10個
- 中央室が赤5個・青5個
- 右室が黒4個・赤4個・青2個
- 上層の縦仕切りが存在
- 3つの第1出口が存在
- y=66〜67は左開口だけ
- y=102〜103は右開口だけ
- 狐が中央帯にない
- 最終開口と狐が同じ側
- 初期30個が固定壁へ接触しない
- 初期配置同士が重ならない
- ゴール直上の到達可能性警告が0

## 13. 実機合格条件

- 無操作では成功しない
- 1室だけ開けても成功しない
- 画面中央を縦に一本掘るだけでは第2障壁を越えない
- 左を縦に掘り続けるだけでは第3障壁を越えない
- 最低2室を開放し、左→右の誘導を行えば20個成功できる
- 狐が右端にいることが一目で分かる
- 少なくとも上画面と下画面を確認する必要がある
- 横方向の砂削りが必須になる
- 60秒以内で現実的にクリアできる
- 左＋中央と中央＋右でリスクと得点差を体感できる
- 平面振動、掘削幅、結果、ランキングに回帰がない

## 14. 禁止事項

- 狐を中央へ戻さない
- 中段と最終開口を同じ側にしない
- 固定壁を装飾だけにして真下ルートを残さない
- 危険ゾーンで必須開口を完全に塞がない
- 20個成功、60秒、スコア式を難易度調整目的で変更しない

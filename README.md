# たばコン

公開URL: https://chameleonjp.codeberg.page/tabakon/

game_slug: `tabakon`

## 概要

「たばコン」は、砂を削って🚬を🦊の回収ゾーンへ届けるスマホ向けブラウザパズルゲームです。表示Canvasは320×480のまま、内部には320×960の2画面分ある縦長世界を持ち、左端のスクロールバーで上層から下層まで確認しながら遊びます。

30個の🚬のうち20個を届けると成功です。制限時間は60秒です。

ステージは10種類からゲーム開始ごとにランダムで1つ選ばれます。現在は共通の縦長構造を基に、トラップ、仕掛け、ゴール位置などを変えた10種類のステージを用意しています。同じステージが連続する可能性があり、10回遊んでも10種類すべてが出る保証はありません。

## 操作方法

- 名前を入力して「ゲーム開始」を押します。
- 3、2、1のカウント後にゲームが始まります。
- Canvas上を指でなぞると砂を削れます。
- Canvas左端24pxの縦バーをタップ/ドラッグすると、2画面分あるゲーム世界を上下に見られます。
- 左端24pxのバー領域では砂を削らず、カメラ操作だけを行います。
- 最下部へ落ち、ゴールへ戻れない🚬は失われます。
- リタイアボタンで途中終了できます。リタイア前には確認ダイアログが表示され、リタイアすると5000点のペナルティがあります。
- 結果画面の「もう一度」はHOMEへ戻らず、同じ名前のまま3、2、1のカウントから即リトライします。

## 点数

| 種類 | 点数 | 特徴 |
| --- | ---: | --- |
| 白っぽい🚬 | 1000 | 標準の動き。 |
| 赤い🚬 | 1500 | 重くて落ちやすいが、横に転がりにくい。 |
| 青い🚬 | 1300 | 軽くて跳ねやすい。 |
| 黒い🚬 | 1700 | 高得点。ただし危険ゾーンに近づくと失いやすい。 |

上手いプレイの差は、高得点の色を多く届けること、短時間で20個届けること、失う🚬を減らすことで生まれます。

## ランキング仕様

- スコア名: 配達スコア
- 単位: 点
- 順序: 高い方がよい `desc`
- 種別: ベストスコア型 `best`
- game_slug: `tabakon`
- ステージ別ランキングは作らず、全10ステージ共通で配達スコアランキングに送信
- 送信: クリア、失敗、リタイア、マイナススコアを含め、ゲーム終了時に自動で1回だけ送信
- Supabase URL: 共通設定 `https://mlpnjgezrnhdxsxolyzj.supabase.co`
- 送信: `submit_score` RPC（`/rest/v1/rpc/submit_score`）
- 取得: `get_best_score_ranking` RPC
- 通信制限時間: 8秒
- 禁止: `/rest/v1/game_scores` への直接insert、旧ランキングテーブル、管理者用キー、サーバー用キー

## 公開方法

ビルドは不要です。リポジトリの `index.html` をそのまま Codeberg Pages で公開できる構成です。

## 注意事項

- ゲーム本体は `index.html` 1ファイルにHTML/CSS/JavaScriptをまとめています。
- npm、Vite、ビルド環境は不要です。
- 名前は `localStorage` の `tabakon_player_name` に保存しますが、公式ランキングのスコア本体は保存しません。
- SupabaseにはPublishable keyのみを記載しています。
- Canvas表示は320×480のまま、内部世界は320×960です。
- 砂グリッドは48×144で、世界サイズから算出した `CELL_W` / `CELL_H` を使います。
- `cameraY` と `screenToWorld()` により、Canvas自体を960px表示にせず、320×960の世界から320×480の範囲を切り出して表示・入力変換します。
- 端末の `devicePixelRatio` に合わせてCanvas内部解像度を調整しますが、ゲーム内の論理座標は320×480です。
